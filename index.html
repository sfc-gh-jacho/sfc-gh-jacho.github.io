How They Work

Built to Run Safely in Your Account

One script per guide

Download it or copy it step by step. Every step on the page is the same SQL as the file.

Self-contained

Each guide creates its own prefixed database, warehouse and roles, and its cleanup step removes them.

Least privilege

Every guide can run as a dedicated demo role with only the grants it needs. In Cost Chargeback, resource monitors and budget setup still need an administrator.

Synthetic and private

All data is fictional. The pages are static, make no third-party requests and never connect to Snowflake.

Get Started

Three Ways to Use a Guide

  • Run it in Snowsight. Open a guide, download the SQL, paste it into a worksheet and run it top to bottom.
  • Make it your own. Every repository is a GitHub template. Click Use this template to start your own copy, licensed under Apache 2.0.
  • Adapt it with Cortex Code. Each README has example prompts for mapping the guide onto your own tables and thresholds.
